# pixelandbrush-ui-kit

Responsive UI component showcase and vector asset gallery built with HTML5, CSS3, and vanilla JavaScript.

## Overview
This starter repository presents an interactive, self-contained component gallery inspired by design agency aesthetics and e-commerce UI patterns (https://pixelandbrush.com/).

## Features
- **Responsive Product Cards**: Mobile-first responsive card layout for displaying digital assets, components, and design projects.
- **Interactive Category Filter**: Client-side filtering mechanism using vanilla JavaScript for seamless user interaction without page reloads.
- **Clean CSS Custom Properties**: Modern CSS design system using custom properties (variables) for consistent color palettes, typography, spacing, and shadows.

## Structure
- `index.html`: Complete, self-contained UI showcase containing layout, styling, and interactivity.
- `README.md`: Documentation and guide.

## Usage
Simply open `index.html` in any web browser or host it via GitHub Pages to view and interact with the component showcase.
